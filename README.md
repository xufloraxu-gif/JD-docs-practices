## 1.安全注意事项
**电源线**： 请勿使用非原装电源线  
**WIFI 重置**: 长安机身顶部的 ‘RESET’ 孔 5 秒，直到听到语音提示 ‘Reseting system’ 。  
**APP 下载**： 扫描包装盒背面的二维码，下载 ‘JD Smart Home‘ 应用程序。  
## 3. 首次使用指南

请按照以下顺序激活设备：

1. 将充电座靠墙放置，并接通电源。
2.  打开主机顶盖，取出 **黄色绝缘贴**。
3.  将主机放置在充电座上，听到 ‘嘀’ 一声提示音。  
4.  打开手机 APP，点击右上角 ‘+’ 号添加新设备。
